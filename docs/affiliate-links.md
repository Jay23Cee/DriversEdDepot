# Affiliate Link Maintenance

## MyImprov state deep links

- State deep-link paths live in `src/data/myimprovPaths.ts` as `MYIMPROV_STATE_PATHS`.
- Outbound URLs are generated by `buildMyImprovAffiliateUrl(stateName)`.
- If a state path is missing, the app falls back to `buildDefaultMyImprovAffiliateUrl()`.

## How to update links

1. Update the state path in `MYIMPROV_STATE_PATHS` for the relevant state.
2. Keep paths relative to `https://www.myimprov.com` (for example `/defensive-driving/texas/tx-online-course/`).
3. Do not hardcode affiliate query values in components; keep them centralized in `MYIMPROV_AFFILIATE_QUERY`.

## Verification checklist

- Confirm each edited state path resolves on MyImprov.
- Confirm generated URL still includes `a_aid`, `a_bid`, and `a_cid`.
- Confirm hero CTA, sticky CTA, state page cards, and guide page links route to the expected deep link.
